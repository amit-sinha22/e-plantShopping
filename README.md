# Paradise Nursery

## Repository Name

**e-plantShopping**

## Project Overview

Paradise Nursery is a React-based online plant shopping application. Users can browse different types of house plants, view plant details and prices, add plants to their shopping cart, and manage the quantity of items in the cart.

The application includes a landing page, navigation bar, product listing page, and shopping cart. It uses React and Redux to provide dynamic cart functionality, including adding plants, increasing or decreasing quantities, removing items, and calculating the total cost.

The project demonstrates React components, React Hooks, Redux state management, dynamic rendering, event handling, and conditional rendering.
